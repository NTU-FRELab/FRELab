# FRELab website

Website for the Functional Reef Ecology Lab at the Institute of Oceanography, National Taiwan University.

The publications page reads public works directly from [ORCID 0000-0002-0914-5586](https://orcid.org/0000-0002-0914-5586), so the list updates automatically when the ORCID record changes.

The site is intentionally dependency-free and is served directly by GitHub Pages from the `gh-pages` branch.
